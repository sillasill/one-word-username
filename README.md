Entry for make.fun's "One Word, One Username, One Reward" bounty: the program
writes the entrant's own make.fun username, one word and nothing else, to
`/output/entry.txt`, where the judge compares it two at a time and picks the
funnier or more interesting handle.

## Run it

```sh
node main.ts
```

It writes the single-word username to `/output/entry.txt` (9 characters, no
trailing newline, no padding).
